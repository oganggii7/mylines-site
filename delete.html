마이라인즈 회원 탈퇴(계정 삭제) 안내

Studio Haru가 운영하는 마이라인즈(MyLines) 계정과 데이터를 지우는 방법이에요.

방법 1. 앱에서 바로 탈퇴하기

  1. 마이라인즈 앱을 열고 로그인해요.
  2. 현황 탭 → 위쪽 ⚙️ 설정 → 계정 칸으로 가요.
  3. 맨 아래 🗑 회원 탈퇴 (계정 삭제)를 눌러요.
  4. 확인 칸에 탈퇴라고 입력하고 탈퇴하기를 누르면 바로 처리돼요.

방법 2. 앱 없이 이메일로 요청하기

앱을 지웠거나 열 수 없다면 아래 주소로 이메일을 보내 주세요.

받는 사람: oganggii7@gmail.com
제목: 마이라인즈 회원 탈퇴 요청
내용: 마이라인즈에 가입한 이메일 주소

본인 확인을 위해 가입한 이메일 주소에서 보내 주세요. 다른 주소에서 보내면 가입한 주소로 확인 메일을 드려요. 요청을 받으면 10일 안에 처리하고 결과를 알려 드려요.

탈퇴 요청 메일 쓰기

지워지는 데이터

  • 계정(로그인 이메일)
  • 카드와 복습 기록, 형광펜 표현
  • 일기와 AI와 나눈 대화
  • 앱 설정, 기능별 사용 횟수와 AI 사용량 기록, 보내 주신 의견

탈퇴하면 위 데이터가 서버에서 즉시 모두 지워지고 되돌릴 수 없어요. 필요하면 먼저 앱의 일기 탭 → 일기 내보내기 → 전체 백업으로 파일을 받아 두세요.

남아 있을 수 있는 데이터

  • 유료 구독을 했다면, 전자상거래법에 따라 결제·계약 기록은 5년, 분쟁 처리 기록은 3년 동안 보관해요.
  • 접속 기록은 통신비밀보호법에 따라 최대 3개월 보관한 뒤 지워져요.
  • 휴대폰에만 저장된 정보(앱 잠금 비밀번호, 타이틀 사진, 저장된 음성)는 앱에서 탈퇴하면 함께 지워지고, 이메일로 요청한 경우에는 앱을 지우면 사라져요.

유료 구독은 탈퇴와 별개예요. Google Play → 결제 및 정기 결제에서 따로 해지해 주세요.
